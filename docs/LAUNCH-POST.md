## Long (Mastodon / LinkedIn / Threads / Reddit body)

Today I'm launching Lahza (Urdu for "a brief moment") — a native studio for screenshots, screen recordings, and motion on Linux.

Linux has great capture tools, but the "make it look good" step usually meant leaving for a web app or a Mac. Lahza puts that whole workflow in one native desktop app, written in Rust with GPUI.

What you can do:
📸 Capture screenshots and annotate them — arrows, shapes, text, numbered steps, highlights, blur, pixelate
🎬 Record your screen with pause/resume, microphone + system audio, and draft recovery if the session dies
✂️ Edit recordings as projects: trim, split, speed ramps, motion regions, timed annotations
🎨 Style anything with backgrounds, window frames, shadows, borders, watermarks, and 3D media transforms
✨ Turn stills into animated scenes and cursor walkthroughs with eight built-in templates
📦 Export PNG, MP4, WebM, or GIF

Install:
• Ubuntu 24.04 — grab the .deb from GitHub Releases
• Any distro with snapd — `sudo snap install lahza`
• Or build from source

https://github.com/FarhanAliRaza/lahza

It's early. Desktop capture depends on your compositor and portals, and live webcam capture is still in progress. If you try it on your desktop — GNOME, KDE, Sway, whatever — I'd love to hear what breaks.
